# X3Trainer

X3Trainer is an AR fitness coach built for the RayNeo X3 Pro smart glasses. During a workout the center of the display stays completely empty so the wearer keeps full situational awareness outdoors, while a sports timer sits pinned to the top edge and live heart-rate and cadence telemetry sits pinned to the bottom, tinted by cardiac zone. All coaching is delivered as spoken audio rather than on-screen text, with an enthusiastic voice guiding pace, heart-rate zone, and interval transitions. A separate mat-coach mode switches things up with a full-body OpenGL vector skeleton that performs each exercise alongside the wearer across a library of bodyweight and dumbbell circuits, tracking reps, timed holds, and workout history automatically.

## Controls

- Single tap — start/pause the timer, or confirm a pending mode switch
- Double tap — reset the timer, or cancel a pending switch
- Triple tap — open settings
- Swipe left/right — cycle timer type (tap to confirm) or adjust a setting value
- Swipe up/down — open the mat coach, or change the mat-coach program
